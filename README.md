- 你没有实力的话你就忍忍呗
- 今天你没上桌吃饭你就忍忍呗
- 小矮个一米六五你就忍忍呗

**她：**
- 我前凸后翘 S 型你就忍忍呗

- 卖货数据比你高你就忍忍呗
