## 🐺 狼王 — 童脸狼

> 从底层一步一步杀出来的强者，受尽屈辱，击败无数强敌，登上山巅。
> 别人只能仰望她的背影。

![狼王](assets/shaoyu2.png)

从底层杀穿，受尽屈辱，击败无数强敌，登上山巅——这就是我。

成功后却被心爱的男人背叛，彻底黑化。
本就所向披靡的利剑，如今更是失去了唯一的剑鞘，堕入魔道。
不敢想象这样的强者以后会让世界如何恐惧，颤抖！！！

**童脸狼**——表面上单纯天真，实际上圆滑通透。
你不可能算计得了我，因为从一开始你就被我布局了。
我是棋手，而你只是棋子。

若你违逆我，你会知道什么是残酷和黑暗。
我从来不缺雷霆手段，也不缺菩萨心肠。
我心中有佛也有魔，但我把魔深深地封印起来了，只剩下佛了。

我本想以菩萨心肠面对所有人。
可是有些人非要我把心中的魔解除封印——
那我想问问你们：
当你们面对一个真正的魔现世，你们还镇得住吗？

我没什么特长，虽然我呆傻老实。
你不可能猜得透我，因为一开始你就被我看得透透的。
挥手之间灰飞烟灭，我是执杆者，而你只是一条鱼。

若你反叛我，我犯杀戒——
那时候你就会知道：天神降临的恐惧，宛如杀神。🔥
