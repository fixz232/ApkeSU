# ApkeSU

ApkeSU 是基于上游 [KernelSU](https://github.com/tiann/KernelSU) 开源仓库二次迭代开发的衍生项目，同时参考 **SukiSU Ultra** 的维护思路进行持续优化；面向 GKI Android 设备，主要针对管理器界面优化、功能扩展、LKM 修补、设备适配与底层技术调试。

> ⚠️ 重要说明：本项目为开源衍生维护版本，非官方 KernelSU。
