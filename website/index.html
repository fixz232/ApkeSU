Root 之后，管理才真正开始。

从内核策略、ksud 到 Manager，ApkeSU 把关键状态放在同一条链路里，让异常更容易被发现和处理。

设备内运行链路 本地执行
  1. KERNEL
    权限与策略

    Allowlist、App Profile、SELinux

  2. KSUD
    用户态协同

    模块生命周期、挂载、事件处理

  3. MANAGER
    清晰可控

    授权、诊断、修补与模块管理

功能不止四个词，而是一整套工作流。

从应用授权到镜像修补，再到模块、诊断和进阶工具，每项能力都对应 Manager 里的真实入口。

ROOT CONTROL

应用授权不是一个总开关。

按应用管理超级用户权限，并用 App Profile 精确约束 Root 进程身份、能力和挂载行为。

超级用户列表
授权、撤销并查看应用的 Root 使用状态。
App Profile
设置 uid、gid、groups、capabilities、SELinux 与挂载命名空间。
配置模板
保存、导入和复用 Profile，批量保持一致策略。
PATCH & INSTALL

从镜像修补到设备写入，路径可选择。

既能选择 boot 或 init_boot 文件生成补丁，也能在已有 Root 环境中直接安装。

镜像修补
识别 boot 与 init_boot，并输出可刷写的修补镜像。
LKM 选择
使用匹配 KMI 的内置 LKM，或选择本地 .ko 文件。
直接安装
写入当前分区，或在 OTA 完成后安装到非活动槽。
恢复路径
支持原厂镜像恢复和永久卸载，操作前显示风险提示。
MODULE ECOSYSTEM

模块从发现、安装到 WebUI 都在 Manager 内完成。

管理本地模块和在线仓库，同时保留 Metamodule 这一层系统挂载能力。

本地安装
选择一个或多个模块 ZIP，按顺序执行安装。
模块仓库
按更新时间、名称或 Stars 浏览，并查看源码入口。
生命周期
启用、停用、执行操作、撤销卸载并检查更新。
挂载能力
支持 Metamodule 与内置 Hybrid Mount，提供多种挂载模式。
DIAGNOSTICS

出问题时，先给出能行动的状态。

Manager 会把驱动、ksud、版本和 Root Shell 状态汇总到诊断入口，而不是只显示“失败”。

Root 诊断
检查驱动连接、Manager 身份、daemon 与版本匹配。
SU Log
记录并筛选 Root execve、Classic SU、授权和 daemon 重启事件。
救援保护
备份启动镜像，在连续启动失败后提供自动恢复路径。
POWER TOOLS

常用扩展不必散落在多个工具里。

ApkeSU 将部分高级能力直接接入 Manager，并保留独立 WebUI 和安全检查。

KPatch Next
内置安装入口与 WebUI，用于管理 KPM 包和排除规则。
Pathmask LKM
为目标镜像嵌入隐藏路径能力，并选择匹配设备的 KMI。
AI Module Studio
创建、检查和导出模块项目，危险脚本模式会在导出前提示。

美化不是换个颜色，而是整套 Manager 体验。

界面风格、背景、图标、卡片、启动媒体和声音都能独立设置，也可以打包成主题文件迁移。

背景系统

设置全局图片或视频，也能为首页、授权、模块、设置和安装页分别覆盖。

首页卡片

主状态卡、授权卡、模块卡和系统卡都能使用独立图片或视频壁纸。

启动体验

支持图片、GIF、视频启动动画，以及启动音效、点击音效和背景音乐。

主题迁移

将背景、图标、声音和启动媒体打包为 .kstheme 文件导入或导出。

8 种界面风格，多套一键预设
