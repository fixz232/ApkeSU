ApkeSU — производный проект с открытым исходным кодом, основанный на официальном репозитории [KernelSU](https://github.com/tiann/KernelSU) и проекте [SukiSU-Ultra](https://github.com/SukiSU-Ultra/SukiSU-Ultra). Это менеджер root-доступа на уровне ядра для устройств Android GKI, ориентированный на соответствие KMI, надежную настройку SuSFS, восстановимое обслуживание, улучшение KernelSU Manager, расширения интерфейса, исправление LKM и отладку личных устройств.

## О проекте

Проект наследует структуру лицензирования KernelSU: каталог `kernel/` распространяется по лицензии **GPL-2.0-only** в соответствии с исходным KernelSU и ядром Linux; производный от KernelSU код вне каталога `kernel/` распространяется по лицензии **GPL-3.0-or-later**. Сторонние зависимости остаются под соответствующими лицензиями их разработчиков. Подробности приведены в файле [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md).

## Исходный проект

Основной исходный проект: KernelSU

## Соблюдение лицензий

1. Все изменения и весь производный код остаются открытыми. Полный соответствующий исходный код предоставляется вместе с каждой распространяемой сборкой, включая ядра, APK и модули.
2. Любой пользователь может получать, изменять и распространять проект на условиях применимых лицензий. При повторном распространении необходимо сохранять указание исходного проекта, уведомления о лицензиях и полный соответствующий исходный код.
3. При публичном распространении измененной версии проекта необходимо также опубликовать полный измененный исходный код и указать исходный проект.

> Важно: проект расширяет возможности исходного проекта, сохраняя базовую модель разрешений KernelSU без изменений.
> Тема в стиле MIUI является независимой визуальной реализацией и не использует официальный исходный код Xiaomi.
